# Support

- Bug reports: [open an issue](https://github.com/Nuanst-GmbH/mcp-server-browser/issues/new?template=bug_report.yml).
- In VS Code, run **MCP Server: Browser: Report Issue**. It opens that form with a diagnostics draft filled in. Nothing is sent until you submit the issue, and you can edit the draft first. [PRIVACY.md](PRIVACY.md) lists every field the draft includes and what it leaves out.
